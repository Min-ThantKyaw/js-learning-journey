## JSON.stringify()
`Javascript object or array တွေကို JSON Stringကို ပြောင်းပေးတယ်။`

### When?
`APIကို data ပို့တဲ့ အခါ သို့မဟုတ် Browser ရဲ့ local storage ကို သိမ်းတဲ့ အခါ stringကို သာ သိမ်းလို့ရလို့ ဒါကို သုံးကြတယ်။`

## JSON.parse()
`JSON format ရှိတဲ့ stringကို Javascriptမှာ သုံးလို့ရတဲ့ Object or Arrayကို ပြောင်းပေးတယ်။`

### When?
`Serverကနေ APIနဲ့ dataယူတဲ့အခါ ရလာတဲ့ JSON Stringကို Jsမှာ သုံးလို့ရအောင် JSON.parse() နဲ့ OBjectပြောင်းတဲ့ အခါ။`
