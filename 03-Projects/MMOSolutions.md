# User Roles
- Admin(me)
- Writer(User)
- Reader(User)
## Admin
- Userအကုန်လုံးကို Controlလုပ်နိုင်ရမယ်။
- Writer Approve ပေးနိုင်ရမယ်။
- Post/Userတွေကို Ban/Deleteလုပ်နိုင်ရမယ်။
- Commentတွေကို Ban/Deleteလုပ်နိုင်ရမယ်။
- Dataတွေကို Graphနဲ့ကြည့်လို့ရရမယ်။
## Writer(User)
- Readerလိုအကုန်ရရမယ်။
- Dashoard buttonပါရမယ်။
- Post CRUDလုပ်နိုင်ရမယ်။
- ကိုယ့်Postက commentကို Manageလုပ်ခွင့်ရှိတယ်။
- View Count and Staticကြည့်လို့ရရမယ်။
## Reader(User)
-  အကောင့်ဖွင့်နိုင်ရမည် (Register)၊ Login ဝင်နိုင်ရမည်။
-  Writer များ တင်ထားသော ဆောင်းပါး/အကြောင်းအရာများကို ဖတ်ရှုနိုင်ရမည်။
- ဆောင်းပါးများအောက်တွင် Comment ပေးနိုင်ရမည်။
